# Spend-Wise-Project
 My Spend Wise Project
SpendWise is a personal finance web application designed to help users manage their money effectively. It allows individuals to monitor their income, record daily expenses, and instantly calculate their remaining financial balance.

2. The JavaScript Concepts Implemented
This project incorporates several core programming fundamentals:

Variables & Data Types: Storing numeric values, strings, and application states.

User Input: Interactively gathering data from the user.

Arithmetic Operators: Performing calculations on financial data.

Functions: Organizing reusable blocks of logic to keep code clean and modular.

3. How Variables Are Being Used
Variables are declared using modern JavaScript keywords like const (for values that do not change, such as base configurations) and let (for values that update dynamically, such as running expense totals).
